# Cos’è un system prompt?

Il system prompt (o istruzioni di sistema) è il testo che guida il modello **prima** del tuo messaggio: tono, regole, ruolo, limiti. Tu scrivi la domanda; il system prompt dice «come» deve rispondere. In molti prodotti non lo vedi: è già impostato dall’app.

Serve a tenere uno stile stabile (es. «rispondi in italiano semplice») senza ripetere le stesse regole in ogni chat. Non è magia: resta testo. Se è lungo e confuso, il modello può ignorare pezzi o mescolarli col tuo [prompt](/guida/cose-un-prompt).

## Cosa non è

Non è memoria a lungo termine dell’azienda. Non sostituisce documenti freschi ([RAG](/guida/cose-il-rag)). Non elimina le [allucinazioni](/guida/allucinazioni-ai). Non è lo stesso di un [fine-tuning](/guida/cose-il-fine-tuning): lì cambi i pesi; qui cambi solo le istruzioni in cima al contesto.
